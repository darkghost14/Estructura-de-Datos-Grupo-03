# Sistema de Gestion de Procesos - Laboratorio Clinico (Grupo 03)

Proyecto de **Estructura de datos** (Universidad Continental).
Simulador en consola, hecho en C++, que gestiona procesos de un laboratorio clinico
ficticio con tres estructuras hechas a mano:

- **Lista enlazada:** guarda los procesos registrados.
- **Cola de prioridad:** ordena los procesos listos (prioridad 1 = mayor).
- **Pila:** guarda los bloques de memoria asignados (el ultimo en entrar es el primero en salir).

## Como ejecutarlo
Abrir `SistemaGestionG03.cpp` en **Dev-C++** y pulsar **F11** (Compilar y ejecutar).
O desde la consola: `g++ -o simulador SistemaGestionG03.cpp`
